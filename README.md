# Rajnikant Raman — Personal Resume Site

Personal resume and portfolio site built with vanilla HTML/CSS, hosted on GitHub Pages.

**Live:** [rajnikant7008.github.io](https://rajnikant7008.github.io)

## Stack

- Pure HTML5 / CSS3 — no frameworks
- Font Awesome 4.7 for icons
- jQuery 3.7.1 for smooth scroll and contact form
- [Formspree](https://formspree.io) for contact form handling

## Features

- Dark premium design with glass cards and gradient accents
- Fixed sidebar with nav, social links, and CV download
- Responsive layout (desktop / tablet / mobile)
- SEO: Open Graph, Twitter Card, JSON-LD Person schema, canonical URL
- Accessible: `aria-label` on all icon links, `rel="noopener noreferrer"` on external links

## Local Preview

Open `index.html` directly in a browser — no build step required.

## CV

Place `rajnikant-resume.pdf` in the repo root to enable the Download CV button.
